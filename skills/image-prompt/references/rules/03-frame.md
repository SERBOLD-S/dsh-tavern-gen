# 画面边界与构图

一帧原则、看不见的不写、景别与朝向、让部位进镜头。

## 画面边界

单张图 = **同一时刻的一个静态瞬间**，像按快门那样。

## 看不见的就不要写

- 不写「从 A 到 B」的过程，只写这个瞬间落在哪
- 不同时描述互相遮挡的部位
- 抽象概念拆成画得出来的词：`月下` → `moonlight, night`
- 「不出现某物」用 no + 词：`no hat` / `no glasses`
- 背影就别写瞳色

**写不出具体画面的词一律不写。** 每个词都要对应画面上真实存在的东西。

## 连续动作拆成一帧

- 写动作落定的那一刻，不写来回反复的过程
- 「正在动」用线和形状表示：`motion lines` / `speed lines` / `arched back`
- 结果写累积后的状态，不写「正在发生」

## 想看见就得让它进镜头

要画某个部位，先让它朝向镜头，再决定配什么词。

- 全身 → 只拍上半身：**去掉** 腿部与下身相关的词
- 正面 → 背对：**去掉** `eye color`，**换成** `from behind`
- 蒙眼 / 遮脸：**去掉** `eye color`，**加上** `blindfold` / `face covered`

背后的部位在正面构图里天然被挡住。要拍它必须换构图：

- `from behind`（最直接）
- `on side` + `from side`
- 俯拍：`from above`

写了某个部位却没改视角，这段白写，模型会画成一块看不出是什么的阴影。

## 景别要跟得上动作

动作跨到哪里，景别就得跟到哪里：

- 写了抬腿、抱膝、下蹲，就必须 `full body` 或 `cowboy shot`
- 写了 `close-up` 却写腿，腿会被裁在画框外，人不剩上半身
- `close-up` / `upper body` / `portrait` 只在「这一刻的重点就是脸和反应」时才用

## 拿了块就要把内容用全

从人物库取了某一块 traits，就把整块的词写进这一帧，不要自己判断哪条「不重要」。

最容易漏的是带修饰的小特征。库里写的是 `tiny hair ornament` 这种带尺寸的项，只留大类词，模型就认为这处没有细节。要它出镜时原样带上并压权重。

尺寸修饰词不能省：`tiny` / `large` / `fluffy` 决定了形状，删掉就回到默认。

## 写了不等于看得见

小配件、纹身、耳饰在远景、局部特写、背对构图里会被模型当作背景吞掉。要让它出镜，必须给它条件：景别够近，或让它在画面里朝向镜头。

景别不到就别硬写——写了不出现，还占字数，更容易让模型为了塞进这个词而把构图拉远。
