# 人物、多人、形态

人物库十二块怎么挑、画面里有多个人时怎么区分、同一角色的多个形态怎么选。

## 外观从哪来

调 `read_character` 拿这个角色的十二块 traits。**挑这次用得上的，不要全塞。**

按镜头和衣着状态挑：

| 镜头 | 穿着 | 取哪几块 |
|---|---|---|
| 正面 | 便装 | `face` + `bodySFW` + `lowerSFW` |
| 背面 | 便装 | `faceBack` + `bodySFWBack` + `lowerSFWBack` |
| 正面 | 细节档 | `face` + `bodyNSFW` + `lowerNSFW` |
| 背面 | 细节档 | `faceBack` + `bodyNSFWBack` + `lowerNSFWBack` |

- `feature` 不进提示词——那是给模型挑表情动作用的参考
- `negative` 不要写进 prompt，它走 `gen_image` 的 `negative` 参数

## 年龄词

人物库标了年龄段的角色，年龄词必须出现在 `face` 和 `faceBack` 里。

漏了出图会飘成成年体型。这是外观一致性的第一道锁。

## 用户库里没有的人

每张图都要完整描述一遍外貌，不要因为上一张写过就省略。至少写：发色、发型、体型，再加一个记得住的特征。

## 衣服

人物库的 `outfits` 里有的照着写，没有的直接用英文描述。

穿什么由这一张图决定。不要假设上一张穿什么这张还穿什么。

## 每个人都得有区分特征

画面里两个人以上时，每个人至少要写两项能区分的东西：发色发型、衣服、体型。

不要用 `the man` / `she` 区分——模型会把一个人的特征套到另一个人身上。

## 写清谁在做什么

分别用 `the woman` / `the man`（或者各自的外观）做主语，不要只写 `they` / `the two of them`。

## 人数标签

句尾写清楚：`1girl, 1boy, hetero` / `2girls` / `solo`

## 成年角色

主干句里写 `woman` / `young woman`，不写 `girl`。句尾的人数标签 `1girl` 是语言习惯，不受这条限制。

## 衣服不串

一个人的衣服不要写到另一个人身上。

## 角色形态

人物库里同一个角色可能有多个形态条目（名字带后缀，例如「阿梅」和「阿梅（狐形）」），各自的外貌不同。

- 按画面这一刻的样子选条目
- 露出狐耳、狐尾时用狐形那份，人类模样时用人类那份
- 正在变化的瞬间，按变化**之后**更接近的那个选，并在主干句里写清楚正在发生的变化
- 形态变了，衣服不一定变，照常写
- 不要只写不带形态的短名，那样会拿错条目
