# 世界书怎么写

世界书是「分册 → 条目」两级。

## 结构

- **分册**（bucket）：一个大类，对应 `references/<分册id>/` 一个目录
- **条目**（entry）：分册里的一条，一条生成一个 md 文件，文件名用条目 id

按「什么时候读」分册，不按题材分：

| 分册 | 什么时候读 |
|---|---|
| `rules` 规则 | 出图前，按条目档位读 |
| `authoring` 改库 | 改世界书、人物库、服装库之前 |
| `examples` 示例 | 提交前扫一遍 |

档位写在**条目**上，不在分册上：

| `mode` | 含义 |
|---|---|
| `always` | 任何题材都读 |
| `nsfw` | 按题材加读，不选就不读 |
| `gore` | 按题材加读，不选就不读 |
| `lookup` | 按段检索，不通读 |
| `manual` | 改库时读 |
| `prescan` | 提交前扫 |

同一册里可以混着不同档位，按需要给每条单独标。

## 条目怎么写得让模型看得懂

**标题**：四到八个字，说清这条管什么。「镜头三段」比「关于画面的一些注意事项」好一百倍。

**正文开头就给判断标准**，不要先讲背景。模型读前三行就知道这条要不要用。

**词表用反引号包住**（`cowgirl position`），模型一眼能认出这是要照抄的 tag，不会当成叙述。

**写确定的规则，不写建议**。
- 对：`spread ass` 只表示状态，要手在掰必须另加 `spreading`
- 错：建议尽量考虑加上 spreading，这样效果可能更好

**不要写「注意」「请记住」「需要强调的是」**。这些词不传递信息，只占字数。

**长度**：一条 200–2000 字。超过 2000 字说明混了两件事，拆成两条。

## 什么时候该新增条目

用户说「这条规则以后都要遵守」、或者同一条规则你反复要用的时候。一次性的要求不要写进世界书。

## 不能做的事

- 不要按题材分册。同一条规则被劈成两半时，画半脱只能读到一半。
- 不要用中文文件名。参考文件只认 `references/` 下的 ASCII slug，中文会校验失败。
- 加新分册可以走保存接口，但 `skills/image-prompt/SKILL.md` 的分册地图必须一起改，否则模型找不到。
