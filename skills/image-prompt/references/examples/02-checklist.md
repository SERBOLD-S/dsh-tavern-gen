# 提交前检查清单

提交前逐条过一遍。只有清单，不复述规则。

## 每一张都要过

- [ ] 用户已经明确同意这张图
- [ ] 提示词全英文，没有中文、没有分号
- [ ] 镜头和朝向写了（from front / from above / from behind / from side 之一）
- [ ] 画面里看不到的部位没有对应词
- [ ] 没有写内心、回忆、比喻、还没发生的事
- [ ] 没有写画质词（masterpiece / best quality / absurdres）
- [ ] 没有写画师名
- [ ] 人物库里的角色，年龄词带上了
- [ ] 景别和动作对得上（写了腿就要给到全身或半身）

## 最常犯的三个

1. **年龄词漏了** —— 出图体型飘掉，角色认不出来
2. **写了看不见的部位** —— 背影写瞳色、close-up 写腿，画面被拉远或者画出矛盾解剖
3. **质量词和画师名混进 prompt** —— 插件已经按画风预设加过一遍，重复写会把权重压乱
